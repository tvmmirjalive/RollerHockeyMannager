# Roller Hockey Manager

Jeu de gestion de roller in line hockey, sur la vraie pyramide du championnat de France :
six divisions, du Régional à l'Élite, 74 clubs.

Tu prends un club au plancher de la pyramide et tu le fais monter — effectif, staff,
infrastructures, sponsors, transferts, playoffs et Coupe de France.

## Jouer

Le jeu tourne entièrement dans le navigateur. Aucune installation, aucun compte, aucune
donnée envoyée nulle part : la partie est sauvegardée dans le navigateur, et peut être
exportée en fichier depuis l'onglet Réglages.

## Le jeu hors ligne

Une fois la page chargée, le jeu fonctionne sans connexion. Il n'émet aucune requête
réseau : la police est embarquée, les images et l'audio sont servis depuis ce dépôt.

## Structure

```
index.html      le jeu
images/         bandeaux d'écran, infrastructures, portraits, sponsors
audio/          six boucles musicales et trois jingles
```
